---
title: Procedure
summary: Flush, blow out, dry, and test — in that order.
---

::: tools Tools & materials
- Odorless mineral spirits
- Glass jar and catch tray
- Soft brushes, assorted
- Battery air duster
- Lint-free cloths
- Fine artist's paintbrush (for oil)
- Light machine oil
- Nitrile gloves
:::

## Prepare the machine

![Type basket](images/type-basket.svg "Type basket with the carriage moved fully to the right.")

Remove the machine from its case and set it on the catch tray. Move the carriage fully to one side so the type basket and segment are exposed. Note any sticking type bars before you begin, so you can confirm afterward that cleaning freed them.

## Clean the segment

![Segment slots](images/segment.svg "Segment slots — flush, don't scrub."){.fig-right}

::: steps
1. Raise a small group of type bars at a time so their slots are open.
2. Flood each slot with mineral spirits using a soft brush, letting it drain into the tray.
3. Work each type bar up and down until it falls back freely under its own weight.
4. Blow out the slots with the air duster, working from the center outward.
5. Repeat until no grey residue drains from the slots.
:::

::: caution Don't oil the segment
Oil in the segment collects dust and causes the sluggish type bars you just cleaned out. Leave it dry.[^segment]
:::

## Clean the carriage rails

![Carriage rails](images/carriage.svg "Carriage rails, rear view."){.fig-half}

Wipe both rails with a cloth dampened in mineral spirits, moving the carriage through its full travel. When dry, apply a single drop of light oil with the fine paintbrush to each rail and run the carriage end to end several times.

## Dry and test

Let the machine stand for at least an hour so the solvent evaporates fully. Then type a full character test line in both cases and confirm every type bar returns without hesitation.

[^segment]: A common shop rule — dry segment, sparing oil only on pivots and rails.
